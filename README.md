# Simple GeoLocation App

An Android Kotlin demonstration of retrieving a device's last known location and reverse-geocoding coordinates.

## Features
- Request access to device location
- Retrieve last known coordinates using Google Play Services' fused location provider
- Look up a human-readable location with Android's Geocoder

## Tech stack
Kotlin, Android SDK, Android Studio, Google Play Services Location, Android Geocoder.

## Running locally
Open in Android Studio, sync Gradle, and launch on an Android device/emulator with location services. Grant location permission when prompted. Last-known-location results depend on device settings and availability.

## Notes
This is a learning/portfolio project, not a live location-tracking service.
